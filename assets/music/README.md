# 🎵 assets/music/

Background music and sound effects for your videos.

**The golden rule for audio:** Only use music you are 100% sure is free to use. Safe options:
- Music YOU composed or recorded yourself (safest of all)
- YouTube Audio Library (free with your YouTube account — check each track's license; some require credit)
- Pixabay Music, Uppbeat (free tier), or other royalty-free libraries — read the license terms
- Public domain classical recordings (the *composition* may be public domain, but the *recording* can still be copyrighted — use recordings explicitly marked free)

**Keep a credit log:** For every track you use, save a small text file next to it, e.g. `gentle-lullaby-credit.txt`:
```
Track: Gentle Lullaby
Source: YouTube Audio Library
License: Free to use, credit required
Credit line: "Gentle Lullaby" from YouTube Audio Library
Date downloaded: 2026-09-22
```

**Never use:** popular songs, movie soundtracks, cartoon theme songs, or "free download" MP3s from random sites. If you didn't get it from a trusted free source, don't use it.
