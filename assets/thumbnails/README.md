# 🎨 assets/thumbnails/

Cover images and thumbnails for your videos go here (JPG or PNG).

**Naming:** match the video file, e.g. `the-brave-little-firefly-thumb.jpg`.

**⚠️ Copyright rule:** Only use images you created yourself (your own drawings, AI images you generated, screenshots of your own video) or images that are clearly public domain / CC0 (e.g. from Pixabay, Unsplash, Pexels — check each image's license page). Never use Google Images or cartoon screenshots.
