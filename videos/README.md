# 🎬 videos/

Finished video files go here — one file per story.

**Naming:** `story-slug-resolution.mp4`, for example:
- `the-brave-little-firefly-1080x1920.mp4` (vertical, for Reels / Shorts / TikTok)
- `the-brave-little-firefly-1920x1080.mp4` (horizontal, for YouTube)

**Recommended export settings (free editors like CapCut, VN, or DaVinci Resolve):**
- Format: MP4 (H.264 video + AAC audio)
- Vertical: 1080×1920, 30 fps — for Instagram Reels, YouTube Shorts
- Horizontal: 1920×1080, 30 fps — for regular YouTube videos

**⚠️ Copyright rule:** Only upload videos you made yourself from original or public-domain material. Never upload clips, songs, or characters from movies, cartoons, or other creators. See the main README's copyright section.

**Tip:** GitHub is not great for huge video files. If a video is over 100 MB, either compress it or host it on YouTube / Internet Archive and link it from the story file instead of committing the file here.
