# 🎯 Adaptation Queue — most engaging stories, ranked

This queue feeds the daily pipeline's **adapted story** days. Items are ordered by
engagement (download/read counts and enduring popularity). The pipeline always
takes the **top unadapted item** first, then marks it with the adaptation date.

**License rule (non-negotiable):** verify each item's license before adapting.
Use only public-domain works, or CC BY / CC BY-SA. Never use NC or ND material.
Record full provenance in the story's `credits.md` (title, author, illustrator,
source URL, license, adaptation note).

## Tier 2 — Modern open-licensed picture books (CC BY)

These are contemporary, diverse, and written for today's kids. On each site,
prefer **featured / most-read / award-winning** titles, and check the license
badge on the book's own page before adapting.

- **StoryWeaver** (Pratham Books) — storyweaver.org.in — 38,000+ books, 300 languages
- **African Storybook** — africanstorybook.org — 5,400+ storybooks, 260 languages
- **Book Dash** — bookdash.org — 200+ professionally illustrated picture books
